# 城势 CityScope

城势是一个本地城市经济探索页面。城市搜索会立即展示收录的增长指标、发展评估和统计来源。没有安装本地模型时，页面显示随项目整理的离线评估；启动 Ollama 后，会在搜索时由本机模型根据已收录资料生成文字评估。模型不会联网检索，也不会把行业演示数据当作事实。

## 直接离线查看

双击 index.html 即可使用城市搜索、GDP 对比和内置评估。

## 启用本地 AI

1. 安装 Ollama，并下载轻量中文模型：ollama pull qwen3.5:2b。
2. 确认 Ollama 在本机运行。
3. 双击 start.bat，服务启动后会自动打开页面。
4. 搜索已收录城市即可即时生成评估；点击“重新生成实时 AI”可再次生成。

模型只在本机 Ollama 中运行，项目不会向外发送城市搜索或统计资料。Ollama 未启动或模型不可用时，页面保留内置评估。可通过 OLLAMA_MODEL 环境变量切换模型。

## 城市与资料口径

项目目前收录 17 座城市：北京、上海、深圳、广州、成都、重庆、南京、苏州、武汉、杭州、纽约、东京、伦敦、新加坡、首尔、巴黎和旧金山。每条资料都附有来源链接、年份和统计口径。

各城市可获得的最新年度与指标不同：纽约使用市财政监察长报告中的就业变化估算，不代表 GDP 增速；东京采用东京都 FY2023 财年地区 GDP；伦敦采用 Greater London 2024 年初步实际 GDP；新加坡采用 2025 全年初步 GDP 估算（城邦全国口径）；首尔采用 2024 年地区 GDP；巴黎采用法兰西岛地区 2024 年名义 GDP 增幅，未扣除价格变化；旧金山官方资料未给出市级年度 GDP 增速，因此显示“暂缺”并提供就业和城市活动观察。不同年份、地域边界及统计指标不可直接横向排名。

产业结构和代表企业示例仍为产品演示数据。城市名片中的 GDP 参考体量为独立估算，不应与增长统计混为一谈。
